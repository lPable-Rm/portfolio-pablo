# Caso técnico de Nolvida

Fuente imprimible del PDF enlazado desde la tarjeta de Nolvida en el portfolio.

- `index.html`: contenido y estructura del caso.
- `styles.css`: maquetación A4 y estilos de impresión.
- `summary.html`: versión resumida de una página enlazada desde el portfolio.
- `summary.css`: maquetación del resumen A4.
- `assets/`: material visual propio procedente de la publicación de Nolvida.

Los documentos se generan con Chromium/Chrome en modo headless y se publican como:

- `public/assets/cv/Caso_tecnico_Nolvida_Pablo_Ramos.pdf`: caso detallado.
- `public/assets/cv/Resumen_tecnico_Nolvida_Pablo_Ramos.pdf`: resumen de una página.
